# Averia

Веб-приложение для анализа успеваемости класса. Классный руководитель загружает
выгрузку средних баллов (XLSX) — приложение показывает текущую картину и динамику
по сравнению с предыдущим загруженным файлом.

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Motion ·
Recharts не используется — все графики нарисованы вручную на SVG.

## Запуск

```bash
cd web
npm install
npm run dev
```

Открыть http://localhost:3000. Демо-доступ: `admin@averia.school` / `admin123`.

## Проверки

```bash
npm run typecheck   # tsc --noEmit
npm run verify      # паритет TypeScript-реализации с эталонной арифметикой на Python
```

`verify` читает `web/fixtures/averages-sample.xlsx`, прогоняет его через TS-парсер и
сравнивает результат с payload, посчитанным скриптом
`skills/class-performance-report/scripts/build_dashboard_data.py`. Совпадение должно
быть полным — до каждого поля.

## Структура

| Путь | Назначение |
| --- | --- |
| `web/app` | страницы приложения (дашборд, загрузка, классы, учителя, вход, приглашение) |
| `web/components` | UI-кит и блоки дашборда |
| `web/lib` | арифметика, парсер XLSX, типы, локальное хранилище, seed-данные |
| `web/fixtures` | синтетическая выгрузка для тестов и демо-данных |
| `web/scripts` | генератор фикстуры, генератор seed-данных, проверка паритета |
| `skills/class-performance-report` | Python-инструменты: сборка XLSX-отчёта и статичного дашборда |

## Данные

Все данные в репозитории **синтетические**: фикстура, seed-payloads и сгенерированный
`dashboard.html` используют учеников-плейсхолдеров («Ученик 01…») и класс 9А.

Реальные школьные выгрузки и отчёты исключены через `.gitignore` (`*.xlsx` с
исключением `web/fixtures/`, `Анализ успеваемости*`, `averageMarks*.xlsx`) и никогда
не должны попадать в репозиторий — в них находятся фамилии и классы учеников.

## Арифметика

- Деление округляется по правилу полу-округления: 4,50 → 5, 4,49 → 4.
- Для 7–8 классов применяется порог 4,60 → 5 (округление от x − 0,1).
- `0,00` означает «не аттестован» и отображается как отсутствие, а не как ноль.
- Успеваемость — доля учеников без двоек; качество знаний — доля учеников без двоек
  и троек. Определения всегда идут рядом с числами.
