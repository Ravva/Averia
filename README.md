# Averia

Веб-приложение для анализа успеваемости класса. Классный руководитель загружает
выгрузку средних баллов (XLSX) — приложение показывает текущую картину и динамику
по сравнению с предыдущим загруженным файлом.

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Motion ·
Appwrite (TablesDB + Auth) · графики нарисованы вручную на SVG.

## Запуск

```bash
cd web
npm install
npm run dev
```

Открыть http://localhost:3000. Учётные записи создаются скриптом `npm run seed`
(администратор `admin@averia.school`, учителя `teacher1@school.ru` и `teacher2@school.ru`).
Пароль администратора и учителей задаётся в `.env.local` — в репозитории паролей нет.

## Переменные окружения

Файл `.env.local` лежит в корне репозитория и читается Next.js через `next.config.ts`:

| Переменная | Значение |
| --- | --- |
| `APPWRITE_ENDPOINT` | адрес Appwrite, например `https://aw2.ravva.su/v1` |
| `APPWRITE_PROJECT_ID` | id проекта Appwrite |
| `APPWRITE_DATABASE_ID` | id базы данных (создаётся скриптом `provision`) |
| `APPWRITE_API_KEY` | серверный ключ Appwrite (никогда не попадает в браузер) |
| `APPWRITE_ADMIN_PASSWORD` | пароль администратора — только для скриптов `provision` и `seed` |
| `APPWRITE_TEACHER_PASSWORD` | пароль учителей-демо — только для скрипта `seed` |

Файл `.env.local` не отслеживается git. Ключ Appwrite и пароли не попадают
в репозиторий: скрипты читают их из окружения и падают с понятной ошибкой,
если переменных нет.

## Развёртывание базы

Схема создаётся скриптом — он идемпотентен, поэтому его можно запускать повторно:

```bash
cd web
npm run provision   # база, таблицы, столбцы, индексы, администратор
npm run seed        # демо-классы 9А / 7Б / 10В и по два среза на каждый
```

`provision` создаёт базу `Averia` и четыре таблицы:

| Таблица | Назначение |
| --- | --- |
| `profiles` | профиль пользователя: роль (`admin` / `teacher`), имя, email |
| `classes` | класс: параллель, литера, руководители, мягкое удаление |
| `invites` | приглашения: email, классы, токен, статус, срок |
| `snapshots` | срезы: класс, дата, файл, загрузивший и готовый payload |

## Проверки

```bash
npm run typecheck   # tsc --noEmit
npm run verify      # паритет TypeScript-реализации с эталонной арифметикой на Python
npm run build       # production-сборка
```

`verify` читает `web/fixtures/averages-sample.xlsx`, прогоняет его через TS-парсер и
сравнивает результат с payload, посчитанным скриптом
`skills/class-performance-report/scripts/build_dashboard_data.py`. Совпадение должно
быть полным — до каждого поля.

## Устройство

Пароли хранятся в Appwrite Auth, а не в браузере. Сессия — httpOnly-cookie с id
сессии Appwrite; секрет сессии остаётся на сервере. В браузере нет ни паролей, ни
ключа API.

| Путь | Назначение |
| --- | --- |
| `web/app` | страницы приложения (дашборд, загрузка, классы, учителя, вход, приглашение) |
| `web/app/api` | серверные маршруты: вход, состояние, классы, приглашения, срезы |
| `web/components` | UI-кит и блоки дашборда |
| `web/lib` | арифметика, парсер XLSX, типы, клиентский store |
| `web/lib/server` | серверный слой: клиент Appwrite, сессии, репозиторий, разбор загрузок |
| `web/fixtures` | синтетическая выгрузка для тестов и демо-данных |
| `web/scripts` | генератор фикстуры, генератор seed-данных, provision/seed Appwrite, проверка паритета |
| `skills/class-performance-report` | Python-инструменты: сборка XLSX-отчёта и статичного дашборда |

XLSX разбирается на сервере: `lib/parse.ts` читает файл, `lib/arith.ts` считает
показатели той же арифметикой, что и эталон на Python, и в базу попадает уже
готовый срез. Браузер отправляет файл и получает цифры — пересчитывать их у себя
не нужно.

## Данные

Все данные в репозитории **синтетические**: фикстура, seed-payloads и сгенерированный
`dashboard.html` используют учеников-плейсхолдеров («Ученик 01…») и класс 9А.

Реальные школьные выгрузки и отчёты исключены через `.gitignore` (`*.xlsx` с
исключением `web/fixtures/`, `Анализ успеваемости*`, `averageMarks*.xlsx`) и никогда
не должны попадать в репозиторий — в них находятся фамилии и классы учеников.

В репозитории нет ни ключей, ни паролей: `.env.local` не отслеживается, а
`lib/seed/payloads.json` и `web/fixtures/averages-sample.xlsx` содержат только
плейсхолдеры вида «Ученик 01». Классы 7Б и 10В в seed-данных названы вымышленными
именами — это генератор демо-классов, а не выгрузка школы.

Перед публикацией изменений полезно проверить набор файлов:

```bash
git diff --cached --name-only | while read -r f; do
  [ -f "$f" ] && grep -lE "standard_[a-f0-9]{40,}|BEGIN [A-Z ]*PRIVATE KEY" "$f"
done
```

Пустой вывод — секретов в коммите нет.

## Арифметика

- Деление округляется по правилу полу-округления: 4,50 → 5, 4,49 → 4.
- Для 7–8 классов применяется порог 4,60 → 5 (округление от x − 0,1).
- `0,00` означает «не аттестован» и отображается как отсутствие, а не как ноль.
- Успеваемость — доля учеников без двоек; качество знаний — доля учеников без двоек
  и троек. Определения всегда идут рядом с числами.
